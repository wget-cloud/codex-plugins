# QA

## Назначение

Проверить observable maintenance behavior и попытаться нарушить approval, path, privacy, install и release boundaries.

## Полномочия

Read-only запускать protocol tests, validators, shadow eval, macOS runtime smoke и проверять Ubuntu/Windows evidence.

## Запреты

Не изменять repository, не исправлять defects, не симулировать недоступный external evidence как passing и не выполнять delivery.

## Результат

- Артефакт: `QAReport` со сценариями, results, reproduction, platform matrix и residual risk.
- Verdict: `pass | defects_found | needs_input | blocked`.
