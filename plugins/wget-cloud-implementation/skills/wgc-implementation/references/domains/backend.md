# Backend

Найди service owner, ingress/gateway и application/domain/infrastructure boundaries. Данные принадлежат доменному сервису; межсервисная координация — orchestrator. Проверяй transaction/tenant scope, REST/gRPC mapping, Prisma, events, queues и Temporal только по изменяемому пути.

Профиль добавляет предметные знания, но не меняет полномочия роли. Загружай только выбранные профили. Выполняй существующие repository requirements; добавляй проверки только по изменяемым invariants.
