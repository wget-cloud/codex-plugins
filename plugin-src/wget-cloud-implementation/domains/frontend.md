# Frontend

Проверь фактические imports и data fetching: server truth, RTK Query/SWR cache и local state различны. Проверяй loading/error, cancellation, optimistic updates, realtime ordering, forms, responsive и keyboard/accessibility по риску. UI hiding не заменяет backend access control.

Профиль добавляет предметные знания, но не меняет полномочия роли. Загружай только выбранные профили. Выполняй существующие repository requirements; добавляй проверки только по изменяемым invariants.
